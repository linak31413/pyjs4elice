# JavaScript QA 초·중·고급 실습 코드

첨부 강의자료의 JavaScript 기초(변수, 데이터 타입, 함수, 배열, 객체)와 메서드(String/Array/JSON/Arrow Function/Object/Spread/Destructuring)를 기반으로 구성한 실습 코드다.

## 실행 환경
- Node.js 18 이상 권장
- 외부 npm 패키지 없음

## 실행 예
```bash
node beginner/01_console_variables.js
node intermediate/05_qa_testcase_runner.js
node advanced/04_qa_framework.js
```

## 난이도
- beginner: 따라치기와 결과 예측 중심
- intermediate: 메서드 조합과 QA 데이터 처리 중심
- advanced: 첨부자료 개념을 QA/TC 자동화 구조로 확장

고급 폴더에서 `[응용 확장]`으로 표시된 항목은 첨부자료에서 직접 설명하지 않은 QA 자동화 구조이며, 첨부자료의 배열·객체·함수·JSON·ES6+ 문법을 이용해 확장한 예제다.
